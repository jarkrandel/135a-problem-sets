    Problem 1 (Abbott Exercise 3.2.2): Let \(A = \{(-1)^n + 2/n : n=1,2,3,\ldots\}\) and \(B = \{x \in \Q : 0 < x < 1\}\text{.}\) Answer the questions about limit points, openness/closedness, isolated points, and closure for each set.
    🔗
    Solution:
    🔗
    1. Let \(L_A\) and \(L_B\) denote the sets of limit points of \(A\) and \(B\) respectively. We have \(L_A = \{ -1,1\} \) and \(L_B = [0,1]\text{.}\)
      🔗
      🔗
    2. \(A\) is neither open nor closed: \(A\) contains no intervals, so it cannot be open. On the other hand, \(A\) does not contain its limit point \(-1\text{,}\) so it is not closed.
      🔗
      \(B\) is also neither open nor closed. The density of the irrationals mean any neighborhood of an element of \(B\) contains some irrational point which is not an element of \(B\) by definition. On the other hand, \(B\) has many irrational limit points that it does not contain, so it is not closed.
      🔗
      🔗
    3. We claim every point of \(A\) is isolated except for 1. Indeed, \(A\) is the union of the elements of two sequences that pick out the elements corresponding to odd and even integers in the definition of \(A\text{:}\) \(b_n = (-1)^{2n-1} + \frac{2}{2n-1} = -1 + \frac{2}{2n-1}\) and \(c_n = (-1)^{2n} + \frac{2}{2n} = 1 + \frac{1}{n}\text{.}\) The former sequence converges to -1 while the latter converges to 1. This shows that \(1\) is not isolated. On the other hand, if \(a\in A\) is such that \(a\not=1\text{,}\) then \(a\not=-1\) also so that \(a\) has positive distance from the limits of \((b_n)\) and \((c_n)\text{.}\) This means there exists a neighborhood of \(a\) that contains at most finitely many points of \(A\text{.}\) Therefore, we can shrink this neighborhood so that it contains no points of \(A\) besides \(a\text{,}\) showing \(a\) is isolated.
      🔗
      \(B\) contains no isolated points by the density of the rationals.
      🔗
      🔗
    4. \(\overline{A} = \{ -1\} \cup A\) and \(\overline{B} = [0,1]\text{.}\)
      🔗
      🔗
    Problem 2 (Abbott Exercise 3.2.5): Prove Theorem 3.2.8.
    🔗
    Solution: First, suppose that \(F\) is closed and let \((a_n)\) be a Cauchy sequence such that \(a_n\in F\) for all \(n\in \mathbb {N}\text{.}\) Since \((a_n)\) is a Cauchy sequence, \((a_n)\rightarrow a\) for some \(a\in \mathbb {R}\text{.}\) Our goal is to show that \(a\in F\) using the fact that \(F\) is closed, i.e., it contains its limit points. If there exists an \(n_0\in \mathbb {N}\) such that \(a_{n_0} = a\text{,}\) then \(a = a_{n_0}\in F\text{.}\) If instead \(a_n\not=a\) for every \(n\in \mathbb {N}\text{,}\) then \(a\) is a limit point of \(F\) so that \(a\in F\text{.}\) This completes the proof of the forward direction.
    🔗
    Now, suppose that every Cauchy sequence converges to a point in \(F\text{.}\) Recall that \(F\) is closed if it contains its limit points, so we must show that every limit point of \(F\) is in \(F\text{.}\) Let \(b\) be a limit point of \(F\text{.}\) Then there exists a sequence \((b_n)\) such that \(b_n\in F,\ (b_n)\rightarrow b\) and \(b_n\not=b\) for all \(n\in \mathbb {N}\text{.}\) The fact that \((b_n)\) converges means that it’s a Cauchy sequence whose terms are all contained in \(F\text{,}\) so our hypothesis implies that its limit is contained in \(F\text{.}\) That is, \(b\in F\) as desired.
    🔗
    Problem 3 (Abbott Exercise 3.2.7): Given \(A\subseteq \R\text{,}\) let \(L\) be the set of all limit points of \(A\text{.}\)
    🔗
    1. Intuition: In order to show that \(L\) is closed, we must show that \(L\) contains all of its limit points. In other words, we must show that any point \(x\) that is a limit point of limit points of \(A\) is itself a limit point of \(A\text{.}\) The idea is that we can produce elements of \(A\) arbitrarily close to \(x\) by first getting a limit point of \(A\) very close to \(x\text{,}\) then using that limit point to get an element of \(A\) very close to it. We must be a bit careful to ensure that this element is not actually equal to \(x\text{.}\)
      🔗
      Proof: Let \(x\) be a limit point of \(L\text{.}\) In order to show that \(x\) is a limit point of \(A\text{,}\) we must show that
      🔗
      \begin{equation*} A\cap V_\epsilon (x)\setminus \{ x\} \not=\varnothing \text{ for all } \epsilon {\gt} 0. \end{equation*}
      So, let \(\epsilon {\gt} 0\text{.}\) Since \(x\) is a limit point of \(L\text{,}\) we know that
      🔗
      \begin{equation*} L\cap V_{\epsilon /2}(x)\setminus \{ x\} \not=\varnothing . \end{equation*}
      Let \(\ell \in L\cap V_{\epsilon /2}(x)\setminus \{ x\} \text{.}\) Since \(\ell \not=x\text{,}\) we know that \(|x-\ell | {\gt} 0\text{.}\) The fact that \(\ell \) is a limit point of \(A\) then implies that
      🔗
      \begin{equation*} A\cap V_{|x-\ell |}(\ell )\setminus \{ \ell \} \not=\varnothing . \end{equation*}
      Let \(a\in A\cap V_{|x-\ell |}(\ell )\setminus \{ x\} \text{.}\) The fact that \(a\in V_{|x-\ell |}(\ell )\) implies \(|a-\ell | {\lt} |x-\ell |\text{,}\) so \(a\not=x\text{,}\) while the fact that \(\ell \in V_{\epsilon /2}(x)\) implies \(|x-\ell |{\lt}\frac{\epsilon }{2}\text{.}\) The triangle inequality implies
      🔗
      \begin{equation*} |x-a| \leq |x-\ell | + |\ell -a| {\lt} 2|x-\ell | {\lt} \epsilon . \end{equation*}
      This shows that \(a\in V_{\epsilon }(x)\setminus \{ x\} \text{.}\)
      🔗
      🔗
    2. Let \(x\) be a limit point of \(A\cup L\text{.}\) If \(x\) is also a limit point of \(L\text{,}\) then part (a) means that \(x\in L\text{.}\) On the other hand, if \(x\) is not a limit point of \(L\text{,}\) then there exists \(\epsilon {\gt} 0\) such that \(L\cap V_\epsilon (x)\setminus \{ x\} = \varnothing \text{.}\) This means that for any \(\delta {\lt} \epsilon \text{,}\) \(L\cap V_\delta (x)\setminus \{ x\} = \varnothing \text{.}\) Since \(x\) is a limit point of \(A\cup L\text{,}\) this means
      🔗
      \begin{equation*} \varnothing \not= (A\cup L)\cap V_\delta (x)\setminus \{ x\} = (A\cap V_\delta (x)\setminus \{ x\} )\cup (L\cap V_\delta (x)\setminus \{ x\} ) = A\cap V_\delta (x)\setminus \{ x\} \end{equation*}
      so that \(x\) is a limit point of \(A\text{.}\)
      🔗
      For proof of Theorem 3.2.12, observe that \(\overline{A} = A\cup L\) contains its limit points, so \(\overline{A}\) is closed. On the other hand, any closed set \(F\supseteq A\) contains its limit points, so \(F\supseteq A\cup L = \overline{A}\text{.}\)
      🔗
      🔗
    Problem 4: Neighborhoods of points are a special case of neighborhoods of sets. Let \(A\subseteq \mathbb {R}\) be nonempty. For any \(x\in \mathbb {R}\text{,}\) define the distance of \(x\) to \(A\) by
    🔗
    \begin{equation*} \mathrm{dist}(x,A) = \inf \{ |x-a|:a\in A\} . \end{equation*}
    If \(A\) is finite, this is just the minimal distance of \(x\) to a point in \(A\text{.}\) Given \(r {\gt} 0\text{,}\) we use this to define the open \(r\)-neighborhood of \(A\) by
    🔗
    \begin{equation*} V_r(A) = \{ y\in \mathbb {R}: \mathrm{dist}(y,A) {\lt} r\} . \end{equation*}
    1. Show that if \(y\in \mathbb {R}\) is such that \(\mathrm{dist}(y,A) {\lt} r\text{,}\) then there exists \(a\in A\) such that \(|y-a| {\lt} r\text{.}\)
      🔗
      🔗
    2. Prove that \(V_r(A)\) is open.
      🔗
      🔗
    Solution:
    🔗
    1. Let \(\epsilon = r -\mathrm{dist}(y,A) {\gt} 0\text{.}\) By properties of infima, there exists an element \(c\in \{ |y-a|:a\in A\} \) such that
      🔗
      \begin{equation*} c {\lt} \inf \{ |y-a|:a\in A\} + \epsilon = \mathrm{dist}(y,A) + \epsilon = r. \end{equation*}
      This element \(c\) has the form \(|y-a|\) for some \(a\in A\text{,}\) proving the first claim.
      🔗
      🔗
    2. Intuition: If \(\mathrm{dist}(y,A) {\lt} r\text{,}\) then there is some “room” around \(y\) to fit a neighborhood of points \(z\) such that \(\mathrm{dist}(z,A) {\lt} r\) as well. We can prove the last part using a nice point \(a\in A\) from part (a) to upper bound the distance with the help of the triangle inequality.
      🔗
      Proof: Let \(y\in V_r(A)\text{.}\) This means that \(\mathrm{dist}(y,A) {\lt} r\text{,}\) and part (a) implies that there exists \(a\in A\) such that \(|y-a| {\lt} r\text{.}\) Let \(\epsilon = r - |y-a| {\gt} 0\text{.}\) We claim that \(V_\epsilon (y)\subseteq V_r(A)\text{.}\) Indeed, let \(z\in V_\epsilon (y)\text{.}\) Then
      🔗
      \begin{equation*} |z-a| \leq |z-y| + |y-a| {\lt} \epsilon + |y-a| = r. \end{equation*}
      In particular, this means that \(\mathrm{dist}(z,A) = \inf \{ |z-a|:a\in A\} \leq |z-a| {\lt} r\text{,}\) showing that \(z\in V_r(A)\text{.}\)
      🔗
      🔗
