    Problem 1 (Abbott Exercise 3.2.11(a)): Prove \(\overline{A\cup B} = \overline{A}\cup\overline{B}\text{.}\)
    🔗
    Solution:
    🔗
    1. Let \(L_A\) and \(L_B\) denote the limit points of \(A\) and \(B\) respectively. We need to prove that
      🔗
      \begin{equation*} A\cup B \cup L_{A\cup B} = A\cup B\cup L_A \cup L_B. \end{equation*}
      First, notice that \(L_A,L_B\subseteq L_{A\cup B}\text{.}\) Indeed, if \(x\in L_A\text{,}\) then for any \(\epsilon {\gt} 0\text{,}\) we know that
      🔗
      \begin{equation*} (A\cup B)\cap V_{\epsilon }(x)\setminus \{ x\} \supseteq A\cap V_\epsilon (x)\setminus \{ x\} \not=\varnothing . \end{equation*}
      The same argument works with \(L_B\) in place of \(L_A\text{.}\) We now need to show that \(L_{A\cup B} \subseteq L_A\cup L_B\text{.}\) Let \(x\in L_{A\cup B}\text{.}\) Applying the definition of limit point, this means that for every \(n\in \mathbb {N}\text{,}\) there exists \(y_n\in A\cup B\setminus \{ x\} \) such that \(y_n\in V_{1/n}(x)\setminus \{ x\} \text{.}\) Since there are infinitely many such \(n\text{,}\) one of the following is true: either there exist infinitely many \(n\) such that \(y_n\in A\) or there exist infinitely many \(n\) such that \(y_n\in B\text{.}\) If the former holds, then \(x\in L_A\text{.}\) Indeed, for any \(\epsilon {\gt} 0\text{,}\) there exists some \(n_\epsilon \) such that \(\frac{1}{n_\epsilon } {\lt} \epsilon \) so that \(A\cap V_\epsilon (x)\setminus \{ x\} \supseteq A\cap V_{1/n_\epsilon }(x)\setminus \{ x\} \ni y_{n_\epsilon }\text{.}\) If the latter alternative holds, then \(x\in L_B\) with a nearly identical proof.
      🔗
      🔗
    2. (Bonus) No. Take \(A_n = \{ 1/n\} \) for every \(n\in \mathbb {N}\text{.}\) Then \(\overline{A}_n = \{ 1/n\} \) so that
      🔗
      \begin{equation*} \bigcup_{n\in \mathbb {N}}\overline{A}_n = \{ 1/n:n\in \mathbb {N}\} , \end{equation*}
      yet
      🔗
      \begin{equation*} \overline{\bigcup_{n\in \mathbb {N}}A_n} = \overline{\{ 1/n:n\in \mathbb {N}\} } = \{ 0\} \cup \{ 1/n:n\in \mathbb {N}\} . \end{equation*}
      🔗
    Problem 2 (Abbott Exercise 3.3.1): Show that if \(K\) is compact and nonempty, then \(\sup K\) and \(\inf K\) both exist and are elements of \(K\text{.}\)
    🔗
    Solution: If \(K\) is compact, then it is closed and bounded. The fact that it is bounded means that it is both bounded above and below, so \(\sup K\) and \(\inf K\) exist. To show \(\sup K\in K\text{,}\) notice that for every \(n\in \mathbb {N}\text{,}\) there exists \(a_n\in K\) such that
    🔗
    \begin{equation*} \sup K -\frac{1}{n} {\lt} a_n \leq \sup K. \end{equation*}
    This implies \((a_n)\rightarrow \sup K\text{.}\) Therefore, \(\sup K\in K\) since \(K\) is closed (using Theorem 3.2.8, for example). To show \(\inf K\in K\text{,}\) we use the fact that for every \(n\in \mathbb {N}\) there exists \(b_n\in K\) such that
    🔗
    \begin{equation*} \inf K \leq b_n {\lt} \inf K + \frac{1}{n}. \end{equation*}
    This means \((b_n)\rightarrow \inf K\text{,}\) so \(\inf K\in K\) since \(K\) is closed.
    🔗
    Problem 3:
    🔗
    1. Prove that if \((a_n)\rightarrow a\) and \((b_n)\rightarrow b\text{,}\) then \((|a_n-b_n|)\rightarrow |a-b|\text{.}\)
      🔗
      🔗
    2. Use part (a) to help you complete Abbott Exercise 3.3.8(a).
      🔗
      🔗
    Solution:
    🔗
    1. Let \(\epsilon {\gt} 0\text{.}\) Using the facts that \((a_n)\rightarrow a\) and \((b_n)\rightarrow b\text{,}\) we can an integer \(N_1\in \mathbb {N}\) such that
      🔗
      \begin{equation*} |a_n-a| {\lt} \frac{\epsilon }{2}\text{ whenever } n\geq N_1 \end{equation*}
      and an integer \(N_2\in \mathbb {N}\) such that
      🔗
      \begin{equation*} |b_n-b| {\lt} \frac{\epsilon }{2}\text{ whenever } n\geq N_2. \end{equation*}
      Set \(N = \max \{ N_1,N_2\} \text{.}\) For any \(n \geq N\text{,}\) we can use the triangle inequality to get
      🔗
      \begin{equation*} \big||a_n-b_n| - |a-b|\big| \leq |a_n-b_n - (a-b)| = |a_n-a + b-b_n| \leq |a_n-a| + |b_n-b| {\lt} \frac{\epsilon }{2}+\frac{\epsilon }{2} = \epsilon . \end{equation*}
      Therefore, \((|a_n-b_n|)\rightarrow |a-b|\text{.}\)
      🔗
      🔗
    2. Since \(d = \inf \{ |x-y|:x\in K,\ y\in L\} \text{,}\) for every \(n\in \mathbb {N}\) there exists \(c_n\in \{ |x-y|:x\in K,\ y\in L\} \) such that
      🔗
      \begin{equation*} d \leq c_n {\lt} d-\frac{1}{n}. \end{equation*}
      This means \((c_n)\rightarrow d\text{.}\) By definition there must exist points \(x_n\in K\) and \(y_n\in L\) such that \(c_n = |x_n-y_n|\text{.}\) This gives us sequences \((x_n)\) and \((y_n)\) of points in \(K\) and \(L\) respectively. Since \(K\) is compact, we can extract a subsequence \((x_{n_k})\) that converges to some point \(x_0\in K\text{.}\) We can now examine the subsequence \((y_{n_k})\) and use the compactness of \(L\) to get a further subsequence \((y_{n_{k_i}})\) that converges to some point \(y_0\in L\text{.}\) Since subsequences of convergent subsequences converge to the same limit, we also know that \((c_{n_{k_i}})\rightarrow d\) and \((x_{n_{k_i}})\rightarrow x_0\text{.}\) Part (i) of this problem immediately implies that
      🔗
      \begin{equation*} |x_0-y_0| = \lim_{i\rightarrow \infty }c_{n_{k_i}} = d. \end{equation*}
      Since \(x_0\in K\text{,}\) \(y_0\in L\text{,}\) and \(K\cap L = \varnothing \text{,}\) we know that \(x_0\not=y_0\) so that \(d = |x_0-y_0| {\gt} 0\text{.}\)
      🔗
      🔗
    Problem 4: Let \(K\subseteq \mathbb {R}\) be a finite set. You may assume that
    🔗
    \begin{equation*} K = \{ x_1, x_2,\ldots , x_N\} \end{equation*}
    where \(x_1 {\lt} x_2 {\lt} \ldots {\lt} x_N\text{.}\)
    🔗
    1. Prove that \(K\) is compact using the definition directly.
      🔗
      🔗
    2. Prove that \(K\) is compact by showing that it is closed and bounded.
      🔗
      🔗
    3. Prove that \(K\) is compact by showing that every open subcover of \(K\) has a finite subcover.
      🔗
      🔗
    Solution:
    🔗
    1. Let \((y_n)\subseteq K\text{.}\) We need to show that \((y_n)\) has a convergent subsequence with limit in \(K\text{.}\) Since \(K\) is finite, we claim there must be some element of \(K\text{,}\) call it \(x_i\) for some \(i\) satisfying \(1 \leq i \leq N\) such that \(y_n = x_i\) for infinitely many values of \(n\text{.}\) Indeed, otherwise \((y_n)\) would only take the values \(x_1,\ldots ,x_N\) each finitely many times, resulting in a finite number of terms total. But \((y_n)\) is an infinite list of numbers, so this cannot occur. If we let \(n_k\) denote the index of the \(k\)-th occurrence of \(x_i\) in the sequence \((y_n)\text{,}\) then the subsequence \((y_{n_k})\rightarrow x_i\in K\) since it is just a constant sequence with value \(x_i\text{.}\)
      🔗
      🔗
    2. To show that \(K\) is bounded, we can simply choose \(M = \max \{ |x_1|,\ldots ,|x_N|\} \) as our bound. To show that \(K\) is closed, notice that
      🔗
      \begin{equation*} K^c = \mathbb {R}\setminus K = (-\infty ,x_1)\cup (x_1,x_2)\cup \ldots \cup (x_{N-1},x_N)\cup (x_N,\infty ). \end{equation*}
      This is a union of open intervals, hence is open. Since \(K^c\) is open, we can conclude that \(K\) is closed.
      🔗
      🔗
    3. Let \(\mathcal{U}\) be an open cover of \(K\text{.}\) The fact that \(K\subseteq \bigcup_{\lambda \in \Lambda }U_\lambda \) means that for every \(i\in \{ 1,\ldots , N\} \text{,}\) there exists some open set indexed by \(\lambda_i\) such that \(x_i\in U_{\lambda_i}\text{.}\) Therefore, \(K\subseteq \cup_{i=1}^NU_{\lambda_i}\) so that the collection \(\mathcal{U'} = \{ U_{\lambda_i},\ldots ,U_{\lambda_N}\} \) is an open subcover of \(\mathcal{U}\text{.}\)
      🔗
      🔗
