    1.

    Let \((a_n)\) be a sequence and let \(L\in\mathbb{R}\text{.}\)
    🔗
    1. State the definition of the convergence of \((a_n)\) to \(L\text{.}\)
      🔗
      🔗
    2. Suppose that \((a_n)\rightarrow a\) and \(c\in\mathbb{R}\) satisfies \(c\not=0\text{.}\) Prove that \((ca_n)\rightarrow ca\) directly using the definition of convergence to a limit.
      🔗
      🔗
    Solution.
    1. The sequence \((a_n)\) converges to \(L\) if for all \(\epsilon > 0\) there exists \(N\in\mathbb{N}\) such that for all \(n \geq N\) it follows that \(|a_n - L| < \epsilon.\)
      🔗
      🔗
    2. If we want to show that \((ca_n)\rightarrow ca\text{,}\) we must use the fact that \((a_n)\rightarrow a\) to show that for a given \(\epsilon>0\text{,}\) there exists \(N\in\mathbb{N}\) such that for all \(n \geq N\)
      🔗
      \begin{equation*} |ca_n - ca| = |c(a_n-a)| = |c||a_n-a| < \epsilon \end{equation*}
      In order to get \(|c||a_n-a| < \epsilon\text{,}\) we choose \(N\) to ensure \(|a_n-a| < \epsilon/|c|\text{.}\)
      🔗
      Proof: Let \(\epsilon > 0\text{.}\) Since \((a_n)\rightarrow a\text{,}\) we can choose \(N\in\mathbb{N}\) such that \(|a_n-a| < \epsilon/|c|\) for all \(n \geq N\text{.}\) To see that this choice of \(N\) works, for any \(n\geq N\)
      🔗
      \begin{equation*} |ca_n-ca| = |c||a_n-a| < |c|\frac{\epsilon}{|c|} = \epsilon. \end{equation*}
      🔗
    🔗
    🔗

    2.

    Prove that the following series either converge or diverge. You may use any of the convergence or divergence tests proved in lecture. (You may also use without proof the fact that \((n^kr^n)\rightarrow 0\) whenever \(k\in\mathbb{N}\) and \(|r| < 1\text{.}\))
    🔗
    1. \(\displaystyle \displaystyle \sum_{n=1}^\infty \frac{1}{n\sqrt{n+1}}\)
      🔗
      🔗
    2. \(\displaystyle \displaystyle \sum_{n=1}^\infty \frac{2^n}{2^n+n}\)
      🔗
      🔗
    3. \(\displaystyle \displaystyle \sum_{n=1}^\infty \frac{(-1)^n}{1+n}\)
      🔗
      🔗
    Solution.
    1. The series \(\sum_{n=1}^\infty \frac{1}{n^{3/2}}\) converges since it is a \(p\)-series with \(p = 3/2 > 1\text{.}\) Because for any \(n\in\mathbb{N}\)
      🔗
      \begin{equation*} 0 \leq \frac{1}{n\sqrt{n+1}} \leq \frac{1}{n\sqrt{n}} = \frac{1}{n^{3/2}} \end{equation*}
      the series \(\sum_{n=1}^\infty\frac{1}{n\sqrt{n+1}}\) converges by the Comparison Test.
      🔗
      🔗
    2. Notice that the general term of this series satisfies
      🔗
      \begin{equation*} \lim_{n\rightarrow\infty}\frac{2^n}{2^n+n} = \lim_{n\rightarrow\infty}\frac{1}{1+n2^{-n}} = \frac{1}{1+0} = 1. \end{equation*}
      Since this limit is nonzero, this series diverges by the Divergence Test.
      🔗
      🔗
    3. For every \(n\in\mathbb{N}\text{,}\) we have
      🔗
      \begin{equation*} \frac{1}{1+(n+1)} \leq \frac{1}{1+n} \end{equation*}
      so that the sequence \(a_n = \frac{1}{1+n}\) is decreasing. Since also \((a_n)\rightarrow 0\text{,}\) this means that the Alternating Series Test implies \(\sum_{n=1}^\infty\frac{(-1)^n}{1+n}\) converges.
      🔗
      🔗

    3.

    Solve the following problems about open and closed sets.
    🔗
    1. State the definition of an open set.
      🔗
      🔗
    2. Determine whether each of the following sets are closed but not open, open but not closed, both open and closed, or neither open nor closed.
      🔗
      \begin{equation*} A = \mathbb{Q}\cap[0,1],\quad B = \mathbb{R},\quad C = \left\{\frac{1}{n} : n\in\mathbb{N},\ n\leq 100\right\}. \end{equation*}
      🔗
    3. Prove that the set \((1,\infty) = \{x\in\mathbb{R} : x > 1\}\) is open using the definition of an open set.
      🔗
      🔗
    Solution.
    1. A set \(A\subseteq\mathbb{R}\) is open if for all \(x\in A\) there exists \(\epsilon > 0\) such that \(V_\epsilon(x)\subseteq A\text{.}\)
      🔗
      🔗
    2. \(A\) is neither open nor closed, \(B\) is both open and closed, and \(C\) is closed but not open.
      🔗
      🔗
    3. Using the definition of open, we must show that for every \(x\in (1,\infty)\) there is an \(\epsilon > 0\) such that \(V_\epsilon(x)\subseteq(1,\infty)\text{.}\) To do this, let \(x\in (1,\infty)\) and take \(\epsilon = x-1\) (this is the distance from \(x\) to 1). We claim that \(V_\epsilon(x) \subseteq (1,\infty)\text{.}\) Indeed, let \(y\in V_\epsilon(x) = (x-\epsilon, x+\epsilon)\text{.}\) Then,
      🔗
      \begin{equation*} y > x-\epsilon = x - (x-1) = 1. \end{equation*}
      Therefore \(y\in (1,\infty)\text{,}\) proving \(V_\epsilon(x)\subseteq(1,\infty)\text{.}\)
      🔗
      🔗

    4.

    Solve the following problems about compact sets.
    🔗
    1. State the definition of a compact set.
      🔗
      🔗
    2. Suppose that \(K\) is closed and bounded. Prove that \(K\) is compact by showing \(K\) satisfies the definition of compactness (you may not use the Heine-Borel theorem).
      🔗
      🔗
    Solution.
    1. A set \(K\subseteq\mathbb{R}\) is compact if for every sequence \((x_n)\subseteq K\) there exists a subsequence \((x_{n_k})\) that converges to a point \(x\in K\text{.}\)
      🔗
      🔗
    2. To show that \(K\) is compact, we must show that for any sequence \((x_n)\subseteq K\text{,}\) there exists a convergent subsequence \((x_{n_k})\) whose limit is in \(K\text{.}\) To do this, let \((x_n)\subseteq K\text{.}\) Since \(K\) is bounded, there exists \(M > 0\) such that \(|y|\leq M\) for all \(y\in K\text{.}\) Since \(x_n\in K\) for all \(n\in\mathbb{N}\text{,}\) this means that \(|x_n| \leq M\) for all \(n\in\mathbb{N}\text{.}\) This proves that \((x_n)\) is bounded. By Bolzano-Weierstrass, there exists a convergent subsequence \((x_{n_k})\) converging to some point \(x\in\mathbb{R}\text{.}\) Since \(K\) is closed, every convergent sequence of points in \(K\) has limit in \(K\text{,}\) meaning \(x\in K\text{.}\)
      🔗
      🔗
    🔗
    🔗

    5.

    Let \(f:\mathbb{R}\rightarrow\mathbb{R}\) be given by
    🔗
    \begin{equation*} f(x) = 3x^2+2 \end{equation*}
    for all \(x\in\mathbb{R}\text{.}\)
    🔗
    1. Give a short proof that \(\lim_{x\rightarrow2}f(x) = 14\) (using any properties of \(f\) or theorems we proved).
      🔗
      🔗
    2. Prove that \(\lim_{x\rightarrow 2}f(x)=14\) using only the \(\epsilon\)-\(\delta\) definition of the functional limit.
      🔗
      🔗
    Solution.
    1. The function \(f\) is a polynomial, so it is continuous. This means
      🔗
      \begin{equation*} \lim_{x\rightarrow 2}f(x) = f(2) = 3(2)^2 + 2 = 14. \end{equation*}
      🔗
    2. Let’s do some preliminary work. Notice that
      🔗
      \begin{equation*} |f(x)-14| = |3x^2+2-14| = 3|x^2-4| = 3|(x+2)(x-2)| = 3|x+2||x-2|. \end{equation*}
      If we ensure that \(|x-2| < 1\text{,}\) then \(-1 < x-2 < 1\) so that adding \(4\) across this inequality gives \(3 < x+2 < 5\) and \(|x+2| \leq 5\text{.}\) Under this assumption, \(3|x+2||x-2| \leq 15|x-2|\text{,}\) so we can choose \(\delta = \min\{\epsilon/15, 1\}\text{.}\)
      🔗
      Proof: Let \(\epsilon > 0\text{.}\) Let \(\delta = \min\{\epsilon/15, 1\}\text{.}\) For any \(x\in\mathbb{R}\) such that \(|x-2| < \delta\text{,}\) we know that \(|x-2| <\delta \leq 1\) so that \(|x+2| \leq 5\text{.}\) This means
      🔗
      \begin{equation*} |f(x)-14| = 3|x+2||x-2|\leq 15|x-2|<15\delta \leq 15\frac{\epsilon}{15} = \epsilon. \end{equation*}
      🔗
    🔗
    🔗

    6.

    Let \(f,g:A\rightarrow\mathbb{R}\) be uniformly continuous.
    🔗
    1. State the definition of uniform continuity for a function \(f:A\rightarrow\mathbb{R}\text{.}\)
      🔗
      🔗
    2. Prove that the function \(h:A\rightarrow\mathbb{R}\) defined by \(h(x) = f(x)+g(x)\) is uniformly continuous. Hint: Use the triangle inequality and an \(\epsilon/2 + \epsilon/2\) argument.
      🔗
      🔗
    Solution.
    1. A function \(f:A\rightarrow \mathbb{R}\) is uniformly continuous if for every \(\epsilon > 0\) there exists \(\delta > 0\) such that for all \(x,y\in A\text{,}\) if \(|x-y|<\delta\) then \(|f(x)-f(y)| < \epsilon\text{.}\)
      🔗
      🔗
    2. Let’s do some preliminary work. Notice that for any \(x,y\in A\text{,}\)
      🔗
      \begin{equation*} \begin{aligned} |h(x)-h(y)| &= |f(x)+g(x) - f(y)-g(y)|\\ &= |(f(x)-f(y)) + (g(x)-g(y))|\\ &\leq |f(x)-f(y)| + |g(x)-g(y)| \end{aligned} \end{equation*}
      we can use the uniform continuity of \(f\) and \(g\) to find a \(\delta\) so that \(|x-y| < \delta\) implies \(|f(x)-f(y)| < \epsilon/2\) and \(|g(x)-g(y)| < \epsilon/2\text{.}\)
      🔗
      Proof: Let \(\epsilon > 0\text{.}\) Since \(f\) is uniformly continuous, we can find \(\delta_1 > 0\) such that for all \(x,y\in A\text{,}\) \(|x-y| < \delta_1\) implies \(|f(x)-f(y)| < \epsilon/2\text{.}\) Since \(g\) is uniformly continuous, we can find \(\delta_2 > 0\) such that \(|x-y|<\delta_2\) implies \(|g(x)-g(y)|<\epsilon/2\text{.}\) Set \(\delta = \min\{\delta_1,\delta_2\}\text{.}\) For any \(x,y\in A\text{,}\) if \(|x-y| < \delta\text{,}\) then \(|x-y| < \delta\leq \delta_1\) so that \(|f(x)-f(y)| < \epsilon/2\) and \(|x-y| < \delta \leq \delta_2\) so that \(|g(x)-g(y)| < \epsilon/2\text{,}\) meaning
      🔗
      \begin{equation*} |h(x)-h(y)| \leq |f(x)-f(y)| + |g(x)-g(y)| < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon. \end{equation*}
      🔗
